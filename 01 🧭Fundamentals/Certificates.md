
Kubernetes has **three major certificates** that focus on different skill areas:
### **CKA — Certified Kubernetes Administrator**

Focuses on:

- Cluster installation
- Cluster operations
- Troubleshooting
- Networking, storage, RBAC  

Basically: _“I run the cluster, I fix the cluster, I break the cluster on purpose.”_

👉 Useful for Ops, SRE, and DevOps roles.

---

### **CKAD — Certified Kubernetes Application Developer**

Focuses on:

- Designing containerized apps
- Deployments, Services, ConfigMaps, Secrets
- Application observability
- Best practices inside K8s

Think: _“I write apps that behave nicely inside Kubernetes.”_

👉 Ideal for backend devs, cloud-native devs.

---

### **CKS — Certified Kubernetes Security Specialist**

Focuses on:

- Securing clusters
- Securing workloads
- Network policies
- Runtime security
- TLS, identities, RBAC, CIS benchmarks

This is like the _“Kubernetes cyber ninja”_ cert.
