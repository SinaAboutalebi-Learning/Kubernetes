Kubernetes follows **Semantic Versioning**:

`major.minor.patch`

- **Major** → API breaking changes
- **Minor** → New functionality (backward compatible)
- **Patch** → Bug fixes and security fixes

**Release & Support Model**

- ~**3 minor releases per year**
- Each release supported for **14 months**
- Security patches are provided for **N-2 versions**

**Why updates matter**  
Running old versions increases the **attack surface** and leaves known vulnerabilities unpatched.
